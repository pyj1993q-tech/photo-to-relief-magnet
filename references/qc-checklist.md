# Delivery QA Checklist

Use this checklist on the actual result before delivery.

## Visual and Physical Readability

- [ ] The physical magnet boundary is immediately visible.
- [ ] The presentation canvas and shadow cannot be mistaken for the magnet body.
- [ ] The structure suits the source: die-cut for a clean isolated subject, framed plaque for a complete scene, or a justified alternative.
- [ ] The subject, landmark, composition, and memory cues remain recognizable.
- [ ] High, middle, and low relief read as distinct layers rather than one uniform bulge.
- [ ] Edges are rounded and connected, with no unexplained holes, floating fragments, broken petals, or needle-like fur.
- [ ] The object does not look like a flat sticker, printed photo, glossy plastic toy, or full 3D figurine.
- [ ] Removed clutter has not returned.

## Content Accuracy

- [ ] No logo, model number, place name, packaging, slogan, or memorial detail was invented.
- [ ] Required text matches the source character for character, including punctuation and line breaks.
- [ ] Any identity change, original-character substitution, or meaningful simplification was explicitly approved and disclosed.
- [ ] No unintended people, limbs, signs, QR codes, brands, props, duplicate subjects, or watermarks appear.

## File Accuracy

- [ ] File dimensions, format, and color mode were checked.
- [ ] Display render, shadowed presentation image, and transparent PNG are labeled distinctly.
- [ ] Any transparency claim was verified with actual alpha values; white pixels and checkerboard pixels do not count.
- [ ] An unsupported alpha-check result was escalated to another image inspection tool, not treated as transparent.
- [ ] Concept art is not labeled as a physical sample, print cut file, CAD model, STL, depth map, or production-ready asset.
- [ ] Manufacturing claims use actual supplier requirements for size, minimum feature, thickness, bleed, color, and material.

## Series Consistency

- [ ] The batch was reviewed side by side.
- [ ] Base white, material, rim thickness, corner language, shadow direction, saturation, relief depth, and detail density feel related.
- [ ] Any special background or structure is a deliberate, explained exception.
